# Security policy / Politique de sécurité

## Supported versions / Versions prises en charge

Only the latest version (stable or beta) receives fixes. / Seule la dernière version (stable ou bêta) reçoit des correctifs.

## Reporting a vulnerability / Signaler une faille

Please do not open a public issue. Use [Report a vulnerability](https://github.com/MilFister/MilfTV/security/advisories/new) (Security tab) to report it privately, with the steps to reproduce it and the version concerned.

Merci de ne pas ouvrir de ticket public. Utilisez [Report a vulnerability](https://github.com/MilFister/MilfTV/security/advisories/new) (onglet Security) pour la signaler de façon privée, avec les étapes pour la reproduire et la version concernée.

Never include real IPTV credentials in a report. / N'incluez jamais de vrais identifiants IPTV dans un signalement.
